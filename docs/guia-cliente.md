# Editar y publicar los viajes de LST

Studio: https://lets-surf-together.sanity.studio/ (requiere tu cuenta con acceso). Web: https://lst-sepia.vercel.app/viajes/.

1. **Cambiar un precio:** abre el viaje → «Fechas y niveles» → «Salidas» → precio por persona. Revisa condiciones de tarifa, señal, PDF y formulario externo para que coincidan. Pulsa **Publicar**.
2. **Marcar completo:** cambia «Disponibilidad» a **Completo** y publica. Se conserva la ficha con sus fechas/precios y se retira la solicitud de plaza. También puedes elegir **Plazas disponibles**, **Últimas plazas** o **Consultar disponibilidad**. No se usa un contador de plazas libres.
3. **Sustituir el PDF:** en «Programa» → **PDF del viaje**, sube el archivo aprobado y publica. Este archivo tiene prioridad sobre la URL anterior del dossier. Comprueba el enlace «Descargar dossier» en la web.
4. **Nueva salida:** crea o duplica un viaje; usa una URL nueva y estable, nombre/fecha/niveles/precio correctos, disponibilidad, programa/inclusiones/exclusiones, fotos con descripción y PDF revisados. Si usas formulario, revisa «Enlace de solicitud aprobado» (vacío usa WhatsApp). Confirma las condiciones comerciales y publica solo cuando esté completo; mientras tanto déjalo en borrador.

Publicar inicia automáticamente una reconstrucción en Vercel. La web cambia cuando el despliegue termina; no es instantáneo. Los borradores y sus ediciones no reconstruyen ni aparecen en la web. Despublicar o eliminar un viaje publicado también reconstruye y lo retira. Un cambio de URL elimina el acceso a la anterior salvo las rutas históricas conservadas; evita cambiar URLs existentes.

Si no ves un cambio, consulta el último despliegue de `lst` en Vercel y su estado **Ready**. Si falla, se conserva la última versión publicada: corrige el contenido indicado y vuelve a publicar. El enlace de reconstrucción es privado y está guardado entre Sanity y Vercel; no debe copiarse a la web. Las solicitudes abren Google Forms o WhatsApp: la plaza la confirma el equipo; no hay pagos ni inventario automático. Los PDF e imágenes del CDN son accesibles por URL y no deben contener secretos o datos personales privados.

Marruecos (ambas salidas) y Senegal usan WhatsApp porque sus formularios externos aún contienen equivalencias porcentuales antiguas. Para activar esos formularios, corrige primero sus condiciones para que coincidan con las señales fijas aprobadas de 270 € / 325 €, revisa el formulario y entonces rellena «Enlace de solicitud aprobado» y publica.
